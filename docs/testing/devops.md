# DevOps·배포·운영 테스트 기준

## 적용 시점

빌드·컨테이너·CI/CD·인프라·배포 설정·DB 운영 절차가 바뀔 때 적용합니다.

아래 항목별 적용·해당 없음과 이유를 task.md에 기록합니다. 적용 항목은 작업의 명령·기대 결과·실행 시점과 연결합니다.

## 판정 시 주의

운영 변경의 점검은 격리된 시험 환경에서 수행합니다. 설정 파일이 존재한다는 것과 실제 실패 차단·복원이 검증됐다는 것을 구분합니다. CI·배포 시스템이 없는 실험은 향후 적용으로 기록하고 현재 통과로 표시하지 않습니다.

필수 항목 실패·미실행·근거 누락은 완료 보류입니다. 수치 목표 미정은 테스트 통과가 아니라 계획 미완료입니다.
