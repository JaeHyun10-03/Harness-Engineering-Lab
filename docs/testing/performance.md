# 성능·부하·복구 테스트 기준

## 적용 시점

속도·처리량·자원·동시 처리·장기 안정성에 영향을 주는 변경에 적용합니다.

아래 항목별 적용·해당 없음과 이유를 task.md에 기록합니다. 적용 항목은 작업의 명령·기대 결과·실행 시점과 연결합니다.

## 판정 시 주의

p95는 요청의 95%가 끝난 시간입니다. 평균만으로 통과시키지 않습니다. 백엔드 임계값은 업무와 환경별로 정하며 전역 고정값을 만들지 않습니다. 웹 참고치는 실사용 모바일·데스크톱별 75번째 백분위에서 LCP ≤2.5초, INP ≤200ms, CLS ≤0.1입니다. Lighthouse의 일반 로딩 실행은 INP를 직접 측정하지 않습니다.

필수 항목 실패·미실행·근거 누락은 완료 보류입니다. 수치 목표 미정은 테스트 통과가 아니라 계획 미완료입니다.
