# AI·LLM·멀티에이전트 테스트 기준

## 적용 시점

제품에 LLM·RAG·도구 실행·멀티에이전트 기능이 있을 때 적용합니다. 개발용 클로드·검증 서브에이전트를 쓴다는 이유만으로 제품 AI 평가를 요구하지 않습니다.

아래 항목별 적용·해당 없음과 이유를 task.md에 기록합니다. 적용 항목은 작업의 명령·기대 결과·실행 시점과 연결합니다.

## 판정 시 주의

확률적 품질은 1회 실행·평균 점수만으로 판정하지 않습니다. 반복 수·표본 수·집계 방식·변동 범위를 먼저 정합니다. 성공률은 성공 사례/전체 평가 사례로 계산하고 타임아웃·실패를 분모에서 빼지 않습니다. 금지 행동 0건은 해당 평가 세트의 결과이지 안전성 보증이 아닙니다. 모델·프롬프트·도구·검색 자료 변경 시 관련 평가를 다시 실행합니다.

필수 항목 실패·미실행·근거 누락은 완료 보류입니다. 수치 목표 미정은 테스트 통과가 아니라 계획 미완료입니다.
