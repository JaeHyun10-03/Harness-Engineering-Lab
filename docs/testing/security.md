# 보안·개인정보 테스트 기준

## 적용 시점

인증·권한·외부 입력·파일·네트워크·비밀·의존성이 있는 기능 및 관련 변경에 적용합니다.

아래 항목별 적용·해당 없음과 이유를 task.md에 기록합니다. 적용 항목은 작업의 명령·기대 결과·실행 시점과 연결합니다.

## 확인 항목

| ID | 대상 | 테스트 방법 | 통과 기준 | 남길 증거 |
| --- | --- | --- | --- | --- |
| SEC-01 | 인증·세션 | 잘못된/만료/폐기 토큰·로그아웃·재사용·요청 제한 확인 | 세션 정책 준수, 인증 우회 0건 | 인증 상태별 요청 결과 |
| SEC-02 | 객체·기능 권한 | 미인증·일반·관리자·다른 소유자·다른 조직으로 요청 | 서버에서 일관되게 거부, 타 사용자 데이터 읽기·변경 0건 | 역할×리소스×행동 표 |

| SEC-08 | 남용·감사 | 과도한 요청·큰 파일·고비용 작업·보안 이벤트 재현 | 자원 제한 동작, 필요한 감사 이벤트 기록, 비밀 로그 없음 | 제한·감사 기록 |

## 판정 시 주의

이 표는 프로젝트의 기본 점검 목록이며 법적·금융 규정 준수 인증이 아닙니다. 요구되는 ASVS 버전·수준·세부 요구사항 ID는 프로젝트 범위에 맞춰 별도로 매핑합니다. 스캔 성공만으로 권한·업무 로직 보안까지 통과 처리하지 않습니다.

필수 항목 실패·미실행·근거 누락은 완료 보류입니다. 수치 목표 미정은 테스트 통과가 아니라 계획 미완료입니다.
