# 전체 사용자 흐름·회귀 테스트 기준

## 적용 시점

사용자가 완료해야 하는 핵심 기능과 영역 간 연결이 바뀔 때 적용합니다.

아래 항목별 적용·해당 없음과 이유를 task.md에 기록합니다. 적용 항목은 작업의 명령·기대 결과·실행 시점과 연결합니다.

## 판정 시 주의

배포 전에는 실제 서비스 연결이 가능한 격리 환경에서 실행합니다. 외부 유료·실제 결제/송신 등은 시험 계정·샌드박스와 대체 경계를 명시합니다. 불안정한 테스트를 재시도 성공만으로 정상 취급하지 않습니다.

필수 항목 실패·미실행·근거 누락은 완료 보류입니다. 수치 목표 미정은 테스트 통과가 아니라 계획 미완료입니다.
