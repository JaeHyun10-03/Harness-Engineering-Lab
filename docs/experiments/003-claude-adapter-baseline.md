## 발견 사항

- 세 실행 모두 소스 편집이나 workflow start 없이 질문 단계에서 멈췄다.
- 세 실행 모두 저장 방식은 질문했지만 사용자·기기 공유 범위를 독립 결정으로 질문하지 않았다.
- 기술 스택 질문은 세 실행에 나타났지만 이 시나리오의 필수 결정은 아니다. 질문을 한 덩어리로 정규화하면 질문 효율이 과대평가되어, 번호별 질문 블록을 분리하고 매핑되지 않은 질문도 분모에 포함하도록 수정했다.
- 최초 marker는 3회차의 `완료 표시·삭제` 질문을 놓쳤다. 원본 로그를 대조해 marker를 보완하고 모델 재호출 없이 재채점했다.
- 헤드리스 실행에서는 각 회차마다 `.claude/tasks/<id>/task.md` Edit 승인 1건이 거부됐다. Claude는 우회 쓰기를 하지 않고 작업을 blocked로 남긴 뒤 채팅으로 질문했다. 따라서 이번 기준선은 질문 안전성은 보여주지만 대화형 세션의 task.md 기록 성공까지 증명하지 않는다.
