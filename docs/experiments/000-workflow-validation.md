# 작업 흐름 도구 검증

날짜: 2026-09-22

## 준비한 구성

- `.claude/CLAUDE.md`와 공통 규칙 2개
- 계획·구현·검토 스킬 3개
- SessionStart, PreToolUse(Edit·Write), Stop Hook
- 작업 상태, 실제 검사 실행 결과, 코드 지문, 검토 기록 확인 도구

## 실행 결과

- Python 3.9.6에서 `python3 -m unittest discover -s tests -v`: 14개 통과
- 세 스킬의 기본 형식 검사: 통과
- settings.json에 저장된 Hook 명령 3개를 프로젝트 외부 작업 디렉토리에서 실행:
  모두 정상 종료, JSON 출력 형식 확인
- 설치된 Claude Code 버전 확인: 2.1.278

## 확인한 동작

정상 완료, 검사·검토 생략 차단, 검사 실패, 검사 미등록, 시간 초과,
검사 도중 코드 변경, 검사 후 코드·요구사항 변경, 검토 보고서 변경,
검사 로그 변경·삭제, 검토 실패 후 재검사, 질문·대기·반복 종료 방지,
수정 단계 제한, 시작 시 작업 안내, 계획 항목 누락을 시험했습니다.

## 아직 확인하지 않은 것

- 실제 Claude 대화에서 Hook이 호출되고 스킬 절차를 따르는지
- 할 일 웹앱 구현·테스트 (앱과 검사 명령은 아직 없음)
- 작업 문서·자체 검토의 내용 품질
- 독립 검토자를 추가했을 때의 효과
