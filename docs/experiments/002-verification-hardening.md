# 완료 게이트·증거 보존 보강

날짜: 2026-09-22

## 수정 전 재현

- 계획 보고서의 `판정: 수정 필요`에도 `start` 종료 코드가 0이었다.
- 검사와 리뷰 뒤 `docs/policy.md`를 바꿔도 `complete` 종료 코드가 0이었다.
- 첫 검사 실패 뒤 재검사하면 `evidence/check-1.log`의 실패 기록이 성공 로그로 덮였다.
- 두 파일의 경계에 같은 바이트열을 이동하면 파일 내용이 달라도 지문이 같았다.

## 변경 후 확인

- 위 사례를 `tests/test_workflow.py`에 각각 회귀 테스트로 추가했다.
- 작업 시작 커밋 후에 이루어진 변경이 커밋된 뒤에도 changes.txt에 남는지 임시 Git 저장소에서 확인했다.
- Git이 무시하는 `.env`를 추가 검사 입력으로 지정했을 때 변경을 감지하는지 확인했다.
- 검사 실패 뒤 후속 명령이 실행되지 않고, 두 실행의 로그와 결과가 모두 남는지 확인했다.

이 기록은 하네스 자체 검증이다. 아직 실제 웹앱이나 금융 서비스의 테스트 통과를 뜻하지 않는다.
