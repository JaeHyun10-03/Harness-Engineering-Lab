프론트·백엔드·전체 사용자 흐름 중 해당 대상을 정한다. 정상·실패·경계값·권한·동시 요청을 검토하고, 제외한 항목은 이유를 기록한다.
작업 완료에 필요한 테스트와 배포 전·후 및 정기 점검을 구분한다.

## 성능 테스트

- 필요 여부와 이유:
- 측정 대상과 실행 명령:
- 측정 환경·데이터 규모·동시 요청 수·실행 시간·반복 횟수:
- 지표와 통과 기준 (응답 시간·처리량·오류율·자원 사용량 중 필요한 항목):
- 변경 전 결과와 측정 조건 (기존 기능 개선 시):
- 결과·로그 저장 위치:

불필요하면 이유만 적고 나머지는 생략한다. 필요한 테스트를 실행하지 못한 것은 생략과 구분한다.
신규 기능으로 변경 전 결과가 없으면 그 이유를 적는다. 목표 수치를 임의로 만들지 않는다.
